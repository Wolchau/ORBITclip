# ORBITclip 7.6.3 · Stabilization

## Краткое ревью
Технический релиз без новых интерфейсных функций. Улучшает надёжность обновлений: теперь проверяем фактическую установку ZIP-патча на копию установленной версии 7.6.2, а также отказ при изменённых файлах и восстановление после сбоя.

## Что изменилось
- Установщик поддерживает `--dry-run`: полная проверка контрольных сумм без изменения файлов.
- Обновление не допускает повторных путей в манифесте, символьных ссылок в промежуточных каталогах и пустых изменений.
- Исправлен откат при исключении после уже завершившейся файловой замены.
- После каждой записи проверяется SHA-256 результирующего файла.
- Резервное копирование выполняется полностью **до** первой записи.
- В CI теперь есть проверка установки реального ZIP-патча, а не только его содержимого.
- Проверяем, что локальные файлы, `README.md`, настройки подключения и существующее окружение не затрагиваются.
- Прогоняем Qt offscreen на Windows и macOS, сохраняем PNG барабана для ручной оценки. Linux Qt-регрессии сохранены.

## Ограничения
- Настоящий macOS/Windows ввод через глобальные горячие клавиши, разрешения доступности и отображение на физическом втором мониторе требуют ручной проверки. CI покрывает отрисовку Qt и геометрию.
- Для обновления **7.6.2 → 7.6.3** используется `ORBITclip_Patch_v7_6_3.zip`. Если исходная версия другая, патч правильно откажет.
- Для первого запуска на новом устройстве доступен `ORBITclip_CleanInstall_v7_6_3.zip`.
- Настройки, история буфера, сообщения и общий Python `venv` сохраняются.
- Работа над 7.7 (встроенное обновление, интерактивное превью барабана, история, переписка) остаётся следующим отдельным релизом.

## Установка
Полностью закрой ORBITclip. Распакуй ZIP-патч и запусти `apply_mac.command` на macOS или `apply_windows.bat` на Windows. Если папка не обнаружена автоматически, укажи каталог установленной версии.
