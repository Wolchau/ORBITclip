# ORBITclip 7.7.1 — обновления без неприятных сюрпризов

## Кратко
Небольшой стабилизационный релиз после 7.7.0. Делает процесс обновления понятнее, расширяет диагностику и убирает тестовый токен подключения из текущих исходных настроек.

## Изменения
- Реальный процент загрузки ZIP, когда GitHub сообщает размер; при неизвестном размере — индикатор ожидания без выдуманных процентов.
- При проверке патча и после его подготовки отображается статус операции.
- История обновлений: проверка версий, подтверждение, начало установки, успешный результат или остановка по ошибке. Журнал хранит последние 120 событий локально и не содержит токенов или содержимого буфера.
- Кнопка «Открыть резервные копии» в диалоге обновлений. Резервирование исходных файлов выполняется перед заменой, откат сохраняется.
- Улучшенные подсказки об ошибках загрузки и подтверждение поведения после закрытия программы: результат установки появится при следующем запуске.
- Тестовый серверный токен удалён из `client_defaults.json` в актуальной ветке. **Важно:** он существовал в старой истории Git; для реальной безопасности его следует отозвать/заменить на сервере. Из истории репозитория токен этим релизом не удаляется.

## Проверки и ограничения
- CI: регрессии, тесты фактической установки патча на копию 7.7.0, проверка хешей, отката и сохранности локальных данных; графическая проверка на Windows/macOS.
- Встроенный установщик из 7.7.0 должен принять новый 7.7.1 ZIP, поскольку формат патча не изменён.
- После выхода из приложения процент выполнения файловых операций не отображается — последующие этапы выполняет отдельный процесс. Их результат и ошибки сохраняются в журнале, доступном при следующем запуске.
- Проверка в CI не заменяет ручной прогон на реальном рабочем столе Windows/macOS.

## Установка
- Предпочтительно: в уже установленном 7.7.0 открыть «Настройки → Обновления», нажать «Проверить», затем скачать и подтвердить 7.7.1. Для закрытого GitHub-репозитория потребуется токен с правом чтения или локальный ZIP.
- Альтернатива: `ORBITclip_Patch_v7_7_1.zip` для 7.7.0 и запуск `apply_mac.command` / `apply_windows.bat`.
- Полный архив новой установки: `ORBITclip_CleanInstall_v7_7_1.zip`.
