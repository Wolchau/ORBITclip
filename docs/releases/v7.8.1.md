# ORBITclip 7.8.1 — обновления через несколько версий

## Кратко
Переход на полноценное обновление с пропуском промежуточных версий. Это новый механизм, доступный **после установки версии 7.8.1**. Предыдущие клиенты 7.8.0 и старше ещё не умеют скачивать цепочки автоматически.

## Как работает
- Пользователь открывает «Обновления → Проверить». Приложение получает страницы со стабильными релизами GitHub, а не только самый последний.
- Для каждого совместимого патча загружается ZIP и читается его реальный манифест `from_version/to_version`. По этим зависимостям строится кратчайший маршрут до последнего стабильного релиза. Номера версий не обязаны идти подряд.
- Все нужные патчи скачиваются и сверяются по SHA-256. Полная цепочка **устанавливается сначала на временную копию рабочих файлов**, без изменения текущего ORBITclip. Проверяются исходные хеши и ожидаемая итоговая версия.
- После явного подтверждения и закрытия приложения процесс повторяет проверку на свежей временной копии, создаёт **общую резервную копию исходной версии**, применяет все патчи по очереди и перезапускает приложение.
- Если сбой случится на любом этапе, механизм пытается восстановить все изменённые файлы до **первой** версии цепочки, а не только до предыдущего шага. Системные журналы фиксируют каждый этап.
- Код `apply_patch.py` из скачанных архивов **никогда не исполняется**. Пользовательские настройки и история остаются вне схемы обновления.

## Ограничения
- Если в истории релизов отсутствует патч, образующий полный маршрут, система покажет понятную ошибку и предложит полную установку. **Она не пропускает обязательные миграции наугад.**
- Первоначальная версия 7.8.1 устанавливается чистым архивом или обычным патчем 7.8.0 → 7.8.1. Только после этого будет доступна новая логика.
- Предварительная загрузка всех доступных патчей может занимать больше времени, чем обновление на один релиз, особенно при ограничениях GitHub. Есть предельные лимиты количества и размеров архивов.
- Автоматический откат рассчитан на обычные ошибки записи/проверки. При аварийном выключении компьютера глобальная резервная копия остаётся на диске, но может потребоваться ручное восстановление.
- Системный прогресс установки после закрытия GUI сохраняется в журнале, а не отображается отдельным интерактивным окном.
- Из-за ограничений Qt CI работу системных горячих клавиш и многоэкранной конфигурации необходимо проверить вручную.

## Установка
Скачать `ORBITclip_CleanInstall_v7_8_1.zip` для новой установки либо `ORBITclip_Patch_v7_8_1.zip` для существующей 7.8.0. Установленная 7.8.1 сможет в дальнейшем обновляться через несколько опубликованных версий за одно действие.
