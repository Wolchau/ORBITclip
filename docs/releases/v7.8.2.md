# ORBITclip 7.8.2 — база накопительных обновлений

## Что меняется
Версия **7.8.2 выпускается как новая чистая установка**. Это новая минимальная базовая версия для автоматического обновления без промежуточных патчей. Установи её отдельно на каждом компьютере; для этого выпуска старого последовательного ZIP-патча нет.

## Обновления после 7.8.2
- При нажатии «Обновления → Проверить» приложение проверяет последний стабильный GitHub Release.
- Вместо десятков промежуточных патчей загружается **один полный ZIP последней версии**, даже если пользователь пропустил несколько выпусков.
- Каждый будущий полный архив содержит `update-manifest.json`: список программных файлов, их размеров и SHA-256. Перед перезапуском проверяются все байты ZIP, а также текущие файлы, которые предстоит заменить или удалить.
- **Ни ZIP-скрипты, ни установщики внутри ZIP не запускаются**: проверенный пакет обрабатывает уже установленный обновлятор.
- После выхода из ORBITclip выполняется резервирование **всех изменяемых файлов до первой записи**, затем обновление. При обычной ошибке записи выполняется полный откат к исходной версии; резервная копия остаётся доступной.
- Содержимое буфера, настройки, `client_defaults.json`, сообщения, локальные наборы очереди, пользовательские файлы и общее окружение Python не изменяются.
- При изменённых локальных файлах программы обновление безопасно останавливается, а не затирает правки.
- При отсутствии полноценного полного ZIP обновление отклоняется с понятной ошибкой, вместо частично установленной цепочки.

## Ограничения
- Механизм доступен **начиная с чистой установки 7.8.2**. Старые установки 7.8.1 и ранее не содержат необходимого манифеста программных файлов. Для первого перехода требуется новая чистая установка; предварительно сохрани резервную копию каталога приложения и пользовательских данных.
- При аварийном прекращении **самого процесса установщика** (например, принудительном отключении питания) резервные копии файлов сохраняются на диске, но автоматический откат без запуска процесса не гарантирован; возможна ручная процедура восстановления. Проверка в CI покрывает исключения и сбои записи, а не отключение питания.
- Работа реальных глобальных горячих клавиш и графики на физических Windows/macOS не может быть полностью подтверждена Qt offscreen-тестами.
- Для доступа к приватному GitHub Release может потребоваться read-only токен, вводимый в окне обновления; он не сохраняется.

## Установка 7.8.2
Открой релиз, скачай **`ORBITclip_CleanInstall_v7_8_2.zip`**, распакуй отдельно и запусти `start_mac.command` либо `start_windows.bat`. Перед заменой старой папки закрой все экземпляры ORBITclip. Не переносить старые файлы программы поверх чистой сборки. Пользовательские данные в домашнем каталоге сохраняются и повторно используются.

Начиная с **последующего** релиза (например, 7.8.3), установленная 7.8.2 должна обновляться сразу на последнюю доступную версию через встроенную кнопку, даже если несколько релизов пропущено.
