# ORBITclip 7.2.2

- **Применить патч:** `install_windows.bat` / `install_mac.command`; установка без ручного копирования.
- Постоянный номер версии на экранах.
- Унифицированные иконки категорий (монохромный пиктограммный язык с цветными метками).
- Подключение: двухколоночная навигация, четыре коротких раздела.
- Пространства: личная история и приватные коллекции по приложениям рядом с общими группами. В личных коллекциях нет публикации по умолчанию.
- Умные действия: сравнительный предпросмотр, диагностика данных, JSON→TSV, профиль/дедупликация CSV, статический анализ SQL и Python, преобразования HTML и ссылок.

Бэкап создаётся в `.orbitclip_patch_backups/` установленного клиента; протокол и пользовательские JSON не изменялись.

Ограничения: нет LLM-анализа и серверных преобразований; Qt окна физически не проверялись на Windows/macOS.
