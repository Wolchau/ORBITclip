# ORBITclip 7.8.8 — быстрая библиотека фрагментов

Целевой релиз качества основного ORBITclip, без расширения отдельного SQL-конструктора.

## Исправлено

- **Быстрее поиск по истории:** набор текста в поиске запускает обновление карточек только после небольшой паузы (160 мс), а не после каждого нажатия клавиши.
- **Удобнее большие коллекции:** библиотека первоначально рисует 40 карточек; кнопка «Показать ещё» добавляет следующие 40. Счётчик показывает число совпадений и число видимых записей.
- **Сохранение прокрутки:** обновление из-за копирования нового текста или изменения избранного больше не сбрасывает позицию просмотра, если фильтры не менялись.
- **Фильтр по времени:** Сегодня (начиная с локальной полуночи), последние 7 дней, последние 30 дней, за всё время. Используется вместе с текущими категориями, поиском и подбором по приложению-источнику.
- **Общие пространства:** длинный список опубликованных записей тоже отображается порциями, без пересоздания всех карточек при поиске.
- **Документация:** README обновлён с устаревшей версии 7.7.0 до текущей версии, исправлены пути установки, лимит вложений, сценарий накопительного обновления и ограничения.

## Безопасность и совместимость

- Хранилище `ClipboardVault` и структура пользовательских файлов не менялись. Порционная загрузка ограничивает только отображение — ничего не удаляется и не обрезается в истории.
- Точный поиск проверяет весь текст записи; защищённые записи не раскрываются и не передаются в экспериментальный поиск по смыслу.
- Мессенджер, 40-МиБ передача, обновлятор, очереди вставки и SQL-среда не изменялись.
- Ничего не отправляется на внешние серверы при поиске и фильтрации.

## Установка

Из установленной **7.8.2+** — обновление через меню «Обновления», скачав один накопительный ZIP. Альтернатива — `ORBITclip_CleanInstall_v7_8_8.zip` (новая установка) или `ORBITclip_Patch_v7_8_8.zip` для соседней версии 7.8.7.

## Проверка

Автоматические тесты проверяют полную историю из сотен записей, фильтрацию по времени и источнику, поиск по длинному содержимому, защищённые записи, отсутствие изменений файлов истории, а также реальный Qt-экран с порционной загрузкой и задержкой поиска. Предусмотрены Linux/Windows/macOS CI, включая Qt offscreen. Полноэкранные режимы и глобальные хоткеи на физических устройствах остаются предметом отдельной ручной проверки.

## Следующее направление

Для **7.9.0** приоритетом является действительно надёжный обмен между устройствами: подтверждения доставки, очередь при временном отсутствии связи и безопасное возобновление передачи файлов после обрыва. Эти функции здесь ещё не реализованы.
