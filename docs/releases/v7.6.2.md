# ORBITclip 7.6.2 — исправление оси барабана

## Кратко
В 7.6.1 соседние грани вращались по диагонали, как скошенный параллелепипед, из-за ошибочного горизонтального смещения `sin(angle) × neighbor_gap`. Исправлено: все грани цилиндра имеют единую вертикальную ось и не уходят по диагонали при прокрутке.

## Подробности
- Настройка `neighbor_gap` теперь управляет **симметричным сужением боковых граней**, не меняя центральную ось.
- Переход между категориями использует плавное затухание без горизонтального скачка.
- Подпись в настройках переименована в «Боковой отступ соседей».
- Компоновки Compact, Classic, Wide и Ribbon, темы, прозрачность и позиционирование на двух мониторах сохранены.
- Отдельный Qt-регрессионный тест проверяет сохранение общей вертикальной оси при промежуточных положениях прокрутки, во всех трёх цилиндрических компоновках, с разными настройками отступа.

## Установка
- Патч 7.6.1 → 7.6.2: `ORBITclip_Patch_v7_6_2.zip`.
- Для новой установки: `ORBITclip_CleanInstall_v7_6_2.zip`.
- Патч проверяет исходные SHA-256 только runtime-файлов, а не README.md; существующие данные и виртуальное окружение не изменяются.
- После остановки ORBITclip распакуйте архив и запустите `apply_mac.command` либо `apply_windows.bat`.
- Для 7.6.0 сначала выполните обновление до 7.6.1, затем этот патч. При несовпадении версии прямое применение 7.6.2 не поддерживается.
