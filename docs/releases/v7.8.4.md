# ORBITclip 7.8.4 — передача файлов до 40 МиБ

## Новое
- Поддержка файлов **до 40 МиБ (41 943 040 байт) на файл** вместо прежних 3 МиБ.
- Для вложений свыше 3 МиБ используется потоковая передача по 2 МиБ: каждый блок шифруется AES-GCM, укладывается в прежние лимиты публичного relay-сервера, подтверждается получателем и повторяется при потере подтверждения.
- Два клиента предварительно договариваются о поддержке нового протокола: крупные блоки не отправляются несовместимым версиям.
- До десяти выбранных файлов можно поставить на отправку, не более двух активных потоков одновременно.
- Получатель собирает файл в ограниченном локальном временном каталоге, проверяет SHA-256 всего файла и сохраняет в Downloads/ORBITclip без перезаписи существующего имени.
- В переписке хранится компактная зашифрованная запись со ссылкой на локальный файл. Крупные зашифрованные блоки в журнал сообщений не попадают.
- Отправка и чтение больших файлов работает в фоновых потоках. Состояние передачи отображается в строке подключения мессенджера.
- Для вложений до 3 МиБ сохраняется прежний формат и обратная совместимость.

## Важно
- **Оба устройства должны использовать ORBITclip 7.8.4+**. Если другое устройство устарело или не в сети, крупный файл не отправится; старые небольшие сообщения останутся совместимыми.
- Получатель должен оставаться онлайн до подтверждения последнего блока. Relay-сервер по-прежнему не хранит файлы или очередь для оффлайн-доставки.
- При сбое сети отдельные блоки могут быть переданы повторно. Неоконченная передача после перезапуска пока не возобновляется автоматически.
- Проверки используют локальный эмулятор пути передачи и настоящие операции AES-GCM/SHA-256; ограничения реального Render-хостинга и скорость интернета зависят от условий сети.
- Для нового максимума нужен не увеличенный запрос к серверу, а дробление на блоки: серверные MAX_POST/MAX_PAYLOAD остаются без изменений.
- Крупные файлы уже не пересылаются через функцию пересылки сообщения — повторно выбери сам файл.

## Установка
Обнови **оба** клиента. Начиная с 7.8.2, встроенное обновление может загрузить полный релиз без промежуточных патчей. Доступны `ORBITclip_CleanInstall_v7_8_4.zip` и патч для 7.8.3 `ORBITclip_Patch_v7_8_4.zip`.
