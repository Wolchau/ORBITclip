# ORBITclip 7.6.1 · Барабан, настройки и несколько мониторов

## Кратко
- Четыре самостоятельных формы вместо единственной жёсткой геометрии.
- Точная настройка прозрачности, соседних записей, заголовка и положения.
- Барабан теперь выбирает монитор по расположению мыши, а не по виджету часов.
- Поддержка дисплеев слева или выше основного (отрицательные координаты).

## Настройки
- Форма: Компактный (318×226), Классический (390×302), Широкий (522×260), Лента (550×186).
- Материал: сохраняются четыре стиля 7.6; их цвета наследуют выбранную тему приложения.
- Размещение: Авто у курсора (новый стандарт), над курсором, под курсором, по центру текущего монитора, рядом с часами.
- Прозрачность всего барабана: 35–100%; соседей: 5–100%.
- Смещение соседей: 0–65 условных пикселей; соседей с каждой стороны: 1–4.
- Заголовок: Плашка, Компактный, Только название, Скрыт. Варианты расположения сверху/снизу и отображения счётчика.
- Изменения настроек сразу применяются к открытому барабану и сохраняются.

## Важные ограничения
- Позиционирование «над курсором» означает **над указателем мыши**, а не координатой каретки стороннего редактора. Геометрия текстового поля внешних приложений недоступна стандартному Qt без специальных API доступности.
- Если над курсором недостаточно места, окно показывается ниже или ограничивается доступными границами экрана.
- Два физических монитора требуют финальной проверки на Windows/macOS: CI тестирует расчёты для нескольких экранов, в том числе отрицательные координаты, и Qt-отрисовку offscreen.

## Выпуск
- Для новой установки: `ORBITclip_CleanInstall_v7_6_1.zip`.
- Для обновления 7.6.0: `ORBITclip_Patch_v7_6_1.zip`.
- Установка патча: закрой приложение, распакуй архив рядом с установленным ORBITclip и выполни `apply_windows.bat` либо `apply_mac.command`. Для другого расположения можно использовать `python apply_patch.py --target "папка программы"`.
- Общий `venv`, личные настройки, история и данные мессенджера не удаляются. Библиотеки не добавлялись.
