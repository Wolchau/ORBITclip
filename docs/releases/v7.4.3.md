# ORBITclip 7.4.3

## Общий Python runtime
- Один venv для всех версий: Windows `%LOCALAPPDATA%\\ORBITclip\\venv`, macOS `~/Library/Application Support/ORBITclip/venv`, Linux `~/.local/share/ORBITclip/venv` (или XDG_DATA_HOME).
- Launcher сверяет установленные версии всех основных зависимостей с requirements-client.txt. При необходимости pip докачивает отсутствующие/несовместимые пакеты; в остальных случаях установка не запускается.
- Существующая `.venv` в папке старого приложения не переносится автоматически: абсолютные пути Python-окружений могут быть непереносимы. Она не удаляется; после успешного запуска с новым runtime её можно удалить вручную.

## Убраны неактуальные модули
- Полностью отключены OCR, захват областей экрана, редактор скриншотов и их интерфейсные действия.
- Удалён модуль orbit_capture.py.
- Убраны Pillow и pytesseract из зависимостей. Уже установленные в общей среде пакеты не удаляются автоматически, чтобы не повредить чужие зависимости.

## Размер обновлений
- Релиз содержит полную версию и отдельный минимальный патч 7.4.2 → 7.4.3.
- Патч заменяет только изменившиеся файлы и удаляет устаревшие, проверяя SHA-256, создавая резервную копию и откатывая изменения при ошибке.
- Запуск патча: `python apply_patch.py --target "путь/к/ORBITclip"`.
- Закрой ORBITclip на время применения патча. Пользовательские данные и venv патч не затрагивает.

## Безопасность
В тестовой конфигурации репозитория по-прежнему присутствует временный токен релея. Не распространять сборку публично до ротации и исключения токена.
