# ORBITclip 7.7.0 · Experience

## Ревью
Первый функциональный выпуск после стабилизации 7.6.3. Теперь обновление выполняется из самого ORBITclip: проверка новой версии на GitHub по запросу пользователя, загрузка и полная проверка патча, безопасная установка после закрытия приложения и возврат к предыдущим файлам при ошибке. Обновление не выполняется автоматически в фоне.

## Возможности
- **Обновления**: окно в настройках и системном трее. Проверяет последнюю версию на GitHub, размер и SHA-256 скачанного архива (когда GitHub указывает digest). Есть кнопка выбора локального ZIP, если GitHub недоступен/репозиторий приватный.
- **Установка**: патч 7.6.3→7.7.0 проходит двойную проверку версии, путей и SHA-256 всех файлов. Код из ZIP *не исполняется*. Установка запускается отдельно только после закрытия ORBITclip. Прошлая версия сохраняется в `.orbitclip_patch_backups`. При отказе в обновлении пользовательские данные и настройки не меняются.
- **Просмотр барабана в настройках**: отображает настоящее QPainter-изображение с фиктивными примерами — без содержимого личного буфера. Материал, форма, прозрачность, число соседей и заголовок обновляются в превью при изменении параметров; стрелки переключают записи. Есть сброс параметров к значениям по умолчанию.
- **История**: у карточки появился быстрый просмотр полной записи в читаемом окне с копированием, добавлением в очередь и преобразованиями. Защищённый текст в предварительном просмотре скрыт.
- **Сообщения**: близкие по времени сообщения одного направления группируются компактнее; локально сохранённые изображения показывают миниатюры. Отправка файлов через перетаскивание и кнопку теперь требует подтверждения списка и размеров. Лимит 3 МБ на файл сохранён.

## Важные оговорки
- Приватный репозиторий GitHub не позволяет автоматически проверять релизы без авторизации; можно воспользоваться локальным ZIP. По желанию CLI использует токен только из переменной окружения `GH_TOKEN` / `GITHUB_TOKEN`, не записывает его в настройки.
- Встроенное обновление 7.7 заработает **начиная с самой 7.7**. Установить 7.7 поверх 7.6.3 в первый раз нужно обычным патчем.
- Встроенное обновление требует последовательных версий. Если установленной версии нет в `from_version` последнего патча, приложение откажет и предложит ручной способ. Это предотвращает частичные апгрейды.
- Новый механизм не использует SQL-редактор и не затрагивает параллельную SQL-ветку.
- Системные горячие клавиши, мониторная конфигурация и пользовательский интерфейс требуют финальной ручной проверки на реальных Windows/macOS.

## Установка
Обновление 7.6.3→7.7.0: `ORBITclip_Patch_v7_7_0.zip`, затем `apply_mac.command` либо `apply_windows.bat`. Для чистой установки: `ORBITclip_CleanInstall_v7_7_0.zip`. Данные пользователя, общие виртуальные окружения и подключения сохраняются.
