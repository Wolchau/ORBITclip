# ORBITclip 7.4.2 (кандидат)

- Windows: проверка физического Ctrl по GetAsyncKeyState, сброс устаревшего состояния хука.
- В настройках: Ctrl+колесо или удержание Ctrl с однократным нажатием Alt для открытия истории, дальнейшее листание колесом с Ctrl. Выбор сохраняется.
- Четыре дополнительные темы: Хвойный лес, Слива, Океан, Крем.
- Селекторы: единое Qt-представление увеличенной высоты вместо нативных выпадающих списков.
- Системные уведомления: клик открывает переписку, общие пространства или центр уведомлений. При последовательных системных уведомлениях используется последнее показанное событие.
- Аналитика: локальные агрегаты русских, латинских букв, цифр, спецсимволов и вхождений слова SELECT, включая сравнение сегодняшнего показателя с днём неделю назад. Содержимое буфера не сохраняется в аналитическую БД. Новые показатели собираются только после обновления.

## Проверки перед релизом

- CI: syntax/import/tests.
- Windows: обычная прокрутка после Ctrl/Alt-Tab, обычное Ctrl+колесо, новый режим Ctrl+Alt, смена режима, удержание и отпускание Ctrl, вставка.
- Windows/macOS: выпадающие элементы во всех окнах, клики по системным уведомлениям, отображение цветовых тем.
- Проверить корректность сохранения настроек и совместимость старой SQLite статистики.

До прохождения GUI-проверок это не стабильная сборка.
