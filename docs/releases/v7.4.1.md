# ORBITclip 7.4.1 — бесрамочный анимированный барабан

Полный самостоятельный клиент для Windows и macOS поверх базового кода 7.4.0. Обновление сервера не требуется.

- Системная рамка и прямоугольная заливка всплывающего барабана убраны; прозрачность окна с пропусканием кликов и колеса к активным приложениям.
- Геометрия цилиндра рассчитывается через синус/косинус: грани сжимаются при уходе от центра, изменяются ширина, глубина и прозрачность.
- Плавное вращение на `QVariantAnimation` с `OutCubic`, около 0,18–0,28 сек. При быстром колесе анимация продолжает движение от текущей промежуточной позиции.
- Сквозная прокрутка и направление вращения поддерживаются в циклических списках, включая случай ровно двух записей.
- Компактная типографика и предпросмотр до двух строк в центральной грани; соседние грани выглядят приглушёнными.
- Выбор обычного всплывающего окна по-прежнему доступен через настройки: никаких изменений в истории буфера или протоколе связи.
- Математика проекции вынесена в `orbit_drum_geometry.py`, чтобы тестироваться без Qt.

## Проверка

Регрессионные тесты Python и структура ZIP проверяются автоматически. Нативное отображение и compositor на физических macOS/Windows следует проверить вручную. Внутри тестового клиента присутствует ранее согласованный токен релея — не публиковать сборки открыто.
