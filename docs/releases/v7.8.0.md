# ORBITclip 7.8.0 · Flow

## Кратко
Визуальная очередь вставки — отдельное лёгкое окно, интегрированное с имеющимися действиями истории, глобальной горячей клавишей и барабаном. Старый механизм последовательной вставки сохранён.

## Возможности
- **Редактор очереди** доступен из истории, системного трея и меню часов. Записи можно перетаскивать, сдвигать стрелками, удалять и просматривать целиком.
- **Прогресс:** счётчик выполненных и оставшихся элементов. Ctrl+Alt+J по-прежнему копирует и вставляет следующий элемент в активную внешнюю программу. Кнопка в редакторе только копирует следующий элемент — чтобы случайно не вставлять его в окно редактора.
- **Объединение:** несколько выделенных записей соединяются переносами строк в порядке очереди в один новый элемент. Максимум 200 000 символов объединённого текста; исходные записи очереди при успешной операции заменяются объединённой.
- **Сохранённые наборы:** пользователь может явно сохранить набор под именем и позднее заменить им текущую очередь. Сохранение требует отдельного подтверждения, поскольку тексты хранятся локально без дополнительного шифрования. До подтверждения очередь остаётся только в памяти и очищается при выходе.
- **Барабан:** переключатель «Барабан: очередь / история» выбирает источник глобальной прокрутки. Выбранный из очереди фрагмент при подтверждении расходуется, оставшиеся сохраняют порядок. Режим очереди не запоминается после закрытия приложения.
- **Совместимость:** `PasteQueue.push(text)`, `pop()`, `preview()` остались совместимыми с 7.7. К защищённым записям нельзя применить исходное действие добавления в очередь; локальные исключения и правила приватности прежние.

## Ограничения
- Очередь предназначена для текстовых фрагментов, а не для двоичных файлов.
- В пользовательском интерфейсе нет фонового автосохранения — это сознательный выбор в пользу приватности.
- Сохранённые наборы в файле `~/.orbitclip_paste_presets.json` не шифруются, но создаются с ограничениями доступа пользователя. Не сохраняйте таким способом пароли и секреты.
- Сборка и автоматические тесты не заменяют проверку глобального ввода на физических двух мониторах/macOS.

## Установка
Патч `ORBITclip_Patch_v7_8_0.zip` применяется **строго к 7.7.1**. Также он доступен через «Настройки → Обновления → Проверить → Скачать и проверить → Установить и перезапустить». Полная установка — `ORBITclip_CleanInstall_v7_8_0.zip`. Пользовательские данные и общие виртуальные окружения не перезаписываются.
