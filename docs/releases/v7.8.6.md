# ORBITclip 7.8.6 — бизнес-семантика SQL Explorer

## Где найти
Открой **SQL Explorer → Подключение**, выбери PostgreSQL, затем на вкладке **«Таблицы»** отметь рабочий набор и перейди в новый постоянный раздел **«Бизнес-семантика»**.

## Что реализовано
- **Таблицы:** бизнес-название, назначение, детализация каждой строки (grain). При первоначальном открытии показываются комментарии из PostgreSQL, если собственное описание ещё не задано.
- **Поля:** бизнес-название, произвольное определение, роль (измерение, показатель, идентификатор, дата/время, денежное поле, статус), единица измерения.
- **Метрики:** собственное название, источник из реального каталога БД, поле, агрегация SUM / AVG / MIN / MAX / COUNT / COUNT DISTINCT / COUNT(*), единицы, определение и пояснения бизнес-ограничений.
- **Связи:** бизнес-описание и ожидаемая кардинальность существующих FK/ручных JOIN.
- **Глоссарий:** локальные определения терминов предметной области.
- **Генерация SQL из определения метрики:** проверенный SELECT для одной таблицы, выбор поля группировки, явные SQL-алиасы и экранирование идентификаторов PostgreSQL. Результат можно скопировать и доработать в SQL Studio; он **не выполняется** автоматически.
- **Экспорт контекста в JSON:** схема, описания, роли, определения метрик и терминов, без паролей/строк БД/данных запросов. Полезен для передачи семантического контекста в локальную модель.

## Хранение и совместимость
- Все определения находятся в прежнем локальном проекте SQL Explorer `~/.orbitclip_sql_projects/<профиль>.json`; проект разделён по хешу сервера, порта, базы и пользователя.
- Изменения в таблицы/комментарии PostgreSQL не записываются. Старые выбранные таблицы, комментарии и позиции ER-схемы сохраняются.
- SQL-генератор принимает исключительно существующие поля и разрешённые агрегации. Произвольные текстовые описания не интерпретируются как исполняемый SQL.
- При обновлении 7.8.2+ используется накопительный полный ZIP с проверкой SHA-256 и откатом. Старые пользовательские данные не затрагиваются.

## Границы реализации
Это **первый перенос бизнес-семантического слоя в основной клиент**, а не полная замена отдельной SQL Studio 0.13.0: здесь пока нет встроенного Ollama text-to-SQL, визуального конструктора сложных JOIN/CTE или автоматического анализа свободных бизнес-вопросов. Определения метрик управляют надёжной, узкой генерацией одного SELECT; описания таблиц/полей/связей пока служат документированием и экспортом контекста. Не следует ожидать, что произвольные фильтры из текста определения попадут в SQL.

## Контроль качества
Проверяются локальное сохранение/восстановление проекта, старые проекты без business-секции, генерация PostgreSQL SQL, отказ в использовании несуществующих столбцов, пользовательские пояснения связей и Qt-переходы между вкладками. CI: Linux, Windows, macOS.

## Установка
`ORBITclip_CleanInstall_v7_8_6.zip` или встроенное обновление из 7.8.2+. Прямое скачивание релиза доступно в GitHub Releases.
