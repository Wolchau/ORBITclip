# ORBITclip 7.3.0 — SQL Explorer

- Новый отдельный SQL Explorer для PostgreSQL: хост, порт, база, пользователь, пароль и TLS.
- Каталог доступных таблиц и представлений, выбор рабочего набора.
- Поля, типы, комментарии из каталога, PK/FK/UNIQUE, пользовательские заметки.
- Автоматические связи FK, ручные ключи соединения и редактируемая ER-схема.
- Автосохранение рабочего проекта в `~/.orbitclip_sql_projects/`. Пароли не записываются.
- Чтение исключительно метаданных PostgreSQL в режиме read-only. Содержимое таблиц не загружается.

Открытие: правый клик по часам → SQL Explorer либо История → ⚙ → SQL Explorer.

Ограничения: пока PostgreSQL, до 150 выбранных таблиц и 24 полей в графическом блоке
(полный перечень доступен на вкладке «Поля»).
