# ORBITclip 7.5.0 — Clean Install

Самостоятельный минимальный архив для первой установки на новом компьютере.

- Один каталог `ORBITclip`, содержащий код приложения, файлы ресурсов, зависимости и сценарии запуска Windows/macOS.
- Не включены `.venv`, тестовые файлы, `__pycache__`, патчи, сборочные инструменты, документация разработчика и исходники отключённого OCR.
- При первом запуске Python 3.10+ создаёт отдельное пользовательское окружение; новые версии используют то же окружение и устанавливают библиотеки только при необходимости.
- Дистрибутив не включает секретный общий токен сервера. Укажи собственные реквизиты подключения после установки.
- Для запуска Windows: `start_windows.bat`; macOS: `start_mac.command` (распаковать архив штатным архиватором).
- Требуются Python 3.10+ и интернет для первой установки зависимостей.
- Это архив с Python-клиентом, а не автономный exe/dmg.
