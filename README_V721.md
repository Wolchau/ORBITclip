# ORBITclip 7.2.1 · обновление интерфейса

Это клиентское обновление. Сервер Render и протокол шифрования менять не требуется. Личная история, категории, доверенные устройства, пространства и параметры остаются в прежних пользовательских файлах.

## Изменения

1. **Библиотека:** слева только категории. В заголовке кнопка ⚙ открывает компактное меню инструментов: редактор категорий, очередь прокрутки, приложения-источники, OCR, снимок экрана, пространства, переписка, остановка записи, очистка истории и настройки.
2. **Библиотека → Личное / Общее:** вместо выпадающего выбора рабочих пространств горизонтальный список вкладок, который можно прокрутить. В личной истории сохранён фильтр приложения-источника; он не публикует личные данные.
3. **Контекстное меню записи:** оставлены «Копировать», «Отправить», «Умные действия», «Опубликовать», «Название и категория», «Зашифровать» и подменю «Кольцевая прокрутка» с приоритетом, исключением и горячей клавишей. Избранное, удаление и открытие ссылки остались на постоянных кнопках карточки и поэтому не дублируются в меню. Пункты имеют иконки.
4. **Сообщения:** ширина пузырей до 354 px, уменьшены внутренние отступы. Действия «Копировать», «Ответить», «Переслать», «Удалить», «Открыть файл» появляются при наведении без изменения высоты сообщения; контекстное меню правой кнопкой также работает.
5. **Диалоги:** адресат выбирается из левой колонки переписки, скрытый дублирующий переключатель удалён.
6. **Иконки:** перерисованы SVG для Python, кода, SQL, HTML, JSON, ссылок и таблиц. Python теперь узнаётся по двухцветному символу.
7. **Анимированные инструкции:** убраны из интерфейса и пакета. Автоматическое окно знакомства при запуске отключено.

## Запуск

* Windows: распакуй ZIP и дважды кликни `start_windows.bat`.
* macOS: распакуй ZIP и запусти `start_mac.command` (может потребоваться разрешить запуск и доступ к вводу).
* При первом запуске Python 3.10+ автоматически создаётся `.venv` и ставятся библиотеки из `requirements-client.txt`.

**Обновление:** закрой старое приложение и распакуй полную папку в новое место. Сохранённые настройки находятся в домашней папке и автоматически подхватываются. Если устанавливаешь только патч поверх 7.2.0, замени файлы патча с сохранением структуры `ORBITclip/`; старые файлы `assets/onboarding` можно удалить вручную, они больше не используются.

## Обязательно учитывать

`client_defaults.json` содержит общий токен Render открытым текстом по прежнему запросу владельца. Не размещай эту сборку публично и не отправляй недоверенным людям.

Автоматические проверки модулей и анализа интерфейсного кода пройдены. Запуск Qt на физических Windows и macOS в среде сборки не проводился (PySide6 отсутствует). Поэтому новая компоновка требует визуальной проверки на устройстве.
