# ORBITclip — запуск одним кликом при установленном Python

## Windows

1. Распакуйте ZIP в обычную папку (не запускайте файлы прямо из архива).
2. Дважды нажмите **start_windows.bat**.
3. При первом запуске потребуется интернет для установки библиотек. PySide6 загружается довольно долго.
4. При следующих запусках снова открывайте тот же BAT-файл; переустановка не нужна.

Python **3.10+** должен быть установлен. Программа использует собственную папку `.venv`, не меняя системные пакеты Python.

## macOS

1. Распакуйте архив, откройте папку.
2. Дважды нажмите **start_mac.command**.
3. Если macOS не разрешает исполнение, откройте Terminal в этой папке и выполните:

   ```bash
   chmod +x start_mac.command
   ./start_mac.command
   ```

Первый запуск потребует доступ к интернету. Для глобальных сочетаний клавиш macOS может запросить разрешения **Универсальный доступ** / **Мониторинг ввода** для Terminal (или Python, в зависимости от запуска).

## Полезное

- Зависимости перечислены в `requirements-client.txt` и автоматически ставятся при первом запуске.
- Можно вручную проверить состояние: `python3 launcher.py --diagnose` (на Windows `py -3 launcher.py --diagnose`).
- Если установка зависимостей прервана, просто запустите файл ещё раз.
- Если используете другую версию Python, удалите **только** папку `.venv` для пересоздания виртуального окружения.
- История и настройки сохраняются в домашней папке пользователя, а не в архиве.
- Этот архив **не содержит токен Render** и не подключает новых пользователей автоматически к общему серверу. Данные авторизации вводятся самим пользователем в приложении.

## Дальше — вообще без Python

Для максимально простой передачи другим людям нужны отдельно собранные подписанные приложения: `ORBITclip.exe`/установщик для Windows и `ORBITclip.app`/DMG для macOS. Из кода одной ОС нельзя надёжно скомпилировать полноценное приложение другой ОС; сборки лучше создавать в соответствующих системах с PyInstaller или Nuitka. Этот ZIP — промежуточное решение для компьютеров, где Python уже есть.
