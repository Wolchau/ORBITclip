# ORBITclip

Менеджер буфера обмена для **Windows и macOS**: быстрая библиотека фрагментов, реалистичный барабан Ctrl+колесо, очередь последовательной вставки, локальные преобразования, защищённый обмен между доверенными устройствами, мессенджер и общие пространства.

**Текущая версия: 7.8.8.** [Релизы и архивы](https://github.com/Wolchau/ORBITclip/releases).

## Чистая установка

1. Скачай **`ORBITclip_CleanInstall_v7_8_8.zip`** из [GitHub Releases](https://github.com/Wolchau/ORBITclip/releases/tag/v7.8.8).
2. Распакуй в **отдельную папку**. Не накладывай исходники на старую установку.
3. Закрой старые копии ORBITclip и запусти `start_windows.bat` на Windows либо `start_mac.command` на macOS.

Требуется Python 3.10+; библиотеки устанавливаются при первом запуске. Общее виртуальное окружение хранится за пределами каталога программы: Windows — `%LOCALAPPDATA%/ORBITclip/venv`, macOS — `~/Library/Application Support/ORBITclip/venv`.

## Обновления

Начиная с чистой установки **7.8.2**, встроенный раздел «Обновления» принимает **один полный накопительный архив**, чтобы перейти на последний релиз, даже если были пропущены промежуточные версии. Приложение запрашивает список стабильных релизов GitHub, проверяет ZIP, сравнивает SHA-256 с манифестом программных файлов, создаёт резервную копию и обновляется после выхода. Есть журнал обновлений и механизм отката при ошибке записи.

Если автоматическая проверка не работает из-за приватного репозитория или недоступности GitHub API, скачай полный ZIP на сайте и используй **«Обновления → Выбрать ZIP…»**. Для установки до базовой 7.8.2+ сначала потребуется новая чистая установка.

## История и барабан

- Библиотека и избранное, пользовательские категории, предпросмотр и поиск по тексту/типу.
- **7.8.8:** ввод в поиске больше не пересоздаёт все карточки на каждую клавишу; окно показывает по 40 записей с кнопкой «Показать ещё», сохраняет позицию при обновлении и фильтрует по периодам «Сегодня», «7 дней», «30 дней», «За всё время». История **не удаляется и не сокращается** из-за пагинации.
- Отдельный экспериментальный поиск по смысловым словарным соответствиям (не LLM).
- Цилиндрический переключатель (барабан) с темами и настройками, очередью вставки, настройкой горячих клавиш, закреплением и исключением из прокрутки.
- Командная палитра: `Ctrl+Shift+Space` при доступности глобального ввода; резервный доступ из трея или меню часов.
- Последовательная очередь: `Ctrl+Alt+J` вставляет следующий элемент. Очередь не сохраняется автоматически; именованные наборы сохраняются только по отдельному действию пользователя.
- ORBIT Extract: извлечение таблиц, значений и идентификаторов из текста с TSV/CSV/JSON экспортом.
- Локальные преобразования SQL, JSON, ссылок, таблиц и текстов без облачных запросов.

## Обмен между устройствами

- E2E-зашифрованные сообщения, одобрение доверенных устройств, общие пространства и уведомления.
- Вложения до **40 МиБ на файл**: новые клиенты (7.8.4+) передают большие файлы зашифрованными частями и сверяют SHA-256. Малые старые вложения до 3 МиБ остаются совместимыми.
- **Важное ограничение:** оба клиента должны быть обновлены и оставаться онлайн до завершения больших передач; продолжение после перезапуска и полноценная очередь офлайн-доставки пока **не реализованы**.

## SQL

Есть SQL Explorer с визуальной схемой и бизнес-описаниями полей, метрик и связей, а также экспериментальным локальным конструктором SQL через Ollama. Развитие SQL-конструктора ведётся **отдельно** от ядра буфера/барабана. Ollama не нужна для ежедневной работы ORBITclip.

## Приватность и надёжность

- Есть исключения приложений и временная приватная пауза 5/15/60 минут.
- Защищённые записи не попадают в интеллектуальную индексацию; передача данных между устройствами выполняется только через явные действия.
- Для глобальных сочетаний macOS может запросить права Accessibility/Input Monitoring. Если источник скопированного текста не распознаётся, используй паузу или исключение соответствующего приложения.
- Сервис обмена требует настройки и взаимно доверенных устройств. Устаревшие тестовые токены в истории репозитория и прежних релизах следует считать раскрытыми; действующий секрет сервера нужно самостоятельно заменить.
- CI проводит Python и Qt offscreen-тесты на Linux/Windows/macOS; реальное поведение глобальных хоткеев и доставки через конкретный публичный relay проверяется дополнительно на физических устройствах.
