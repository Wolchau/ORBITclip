# ORBITclip

Менеджер буфера обмена Windows/macOS с быстрым поиском, барабаном истории, очередью вставки, локальными преобразованиями и защищённым обменом между устройствами.

**Актуальная версия: 7.7.0.**

## Первая установка

Скачай `ORBITclip_CleanInstall_v7_6_0.zip` из [GitHub Releases](https://github.com/Wolchau/ORBITclip/releases), распакуй архив и запусти:

- Windows — `start_windows.bat`.
- macOS — `start_mac.command`.

Нужен Python 3.10+ и интернет при первой установке библиотек. Окружение создаётся **за пределами папки приложения** и сохраняется между выпусками: Windows `%LOCALAPPDATA%/ORBITclip/venv`, macOS `~/Library/Application Support/ORBITclip/venv`.

Если уже установлена 7.5.1, используй `ORBITclip_Patch_v7_6_0.zip`. Патч заменяет только изменённые модули после проверки контрольных сумм; личные данные и общий venv не трогает. Перед установкой полностью закрой приложение.

## Основные возможности

- История, избранное, категории, кнопка поиска по буферу и цилиндрический переключатель Ctrl+колесо (альтернатива Ctrl+Alt).
- Командная палитра: Ctrl+Shift+Space при доступности глобального ввода; всегда доступна через меню трея/часов.
- Очередь последовательной вставки: отправка в очередь из истории или палитры, Ctrl+Alt+J — вставить следующий элемент. Очередь остаётся только в оперативной памяти.
- Контекстные локальные преобразования: SQL, JSON, ссылки, таблицы и текст.
- Исключения приложений из записи и временная приватная пауза на 5/15/60 минут.
- Мессенджер с end-to-end шифрованием и передачей файлов через кнопку либо перетаскиванием в чат (не более 3 МБ на файл).
- Общие пространства и отдельный SQL Explorer. Разработка шаблонов SQL выполняется отдельно и не входит в обновление Flow.
- Несколько цветовых тем, четыре заметно отличающихся оформления барабана.

## Обновления из приложения

Начиная с **7.7.0**, в настройках и трее есть пункт «Обновления». Проверка запускается только вручную, содержимое ZIP проходит двойную SHA-256-проверку и не исполняется как код. Установка выполняется после закрытия программы с резервной копией и откатом. В случае приватного репозитория можно указать токен GitHub с доступом на чтение (только в памяти) или выбрать уже скачанный ZIP.

В настройках барабана есть живой предпросмотр с тестовыми записями и сброс параметров. История получила развёрнутый предпросмотр, мессенджер — компактную группировку сообщений, миниатюры локальных изображений и подтверждение перетаскиваемых файлов.

## Безопасность и ограничения

- Для глобальных сочетаний macOS может потребовать разрешения на мониторинг ввода / Accessibility. Сочетания могут конфликтовать с другими программами; запасной доступ — системный трей.
- Исключение приложения работает только если ОС корректно возвращает его имя. Если источник «Неизвестно», включай явную паузу записи.
- Передача в мессенджере требует настроенного сервера и взаимно доверенных устройств.
- Новые дистрибутивы должны очищать тестовые секреты из `client_defaults.json`. **Старый общий тестовый токен в истории репозитория и прежних релизах нужно считать раскрытым и ротировать.** Не публикуй приватный репозиторий и старые ZIP без ревизии.
- CI выполняет unit и Qt offscreen-тесты. Поведение Windows/macOS хуков на реальном железе проверяется отдельно.

## Разработка

Исходники `orbitclip.py`, `orbit_*.py`, `kinetic_*.py`; ресурсы `assets/`; CI `.github/workflows/`. Работа ведётся в feature-ветках через PR согласно `docs/CONTRIBUTING.md`. Библиотеки устанавливаются по `requirements-client.txt`.
