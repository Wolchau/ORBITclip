ORBITclip 7.2.2 — установка патчем
==================================

1. Полностью закрой ORBITclip (на Windows также через трей → Завершить).
2. Распакуй ZIP рядом с папкой установленного ORBITclip.
3. Windows: двойной клик по install_windows.bat.
   macOS: двойной клик по install_mac.command.
4. Если установок несколько, выбери нужный номер в терминале.
5. После сообщения «Успешно обновлено» запусти ORBITclip как обычно.

Если папка не найдена, можно указать её явно:
  Windows: py -3 apply_patch.py --target "C:\путь\к\ORBITclip"
  macOS:   python3 apply_patch.py --target "/Users/.../ORBITclip"

Патч требует установленную v7.2.1. Если у тебя другая версия,
он не затрёт файлы и сообщит об ошибке.

Токен Render, ключи, история и другие пользовательские JSON не входят в пакет.
Все изменяемые файлы получают резервную копию в
  .orbitclip_patch_backups/v7.2.1_to_v7.2.2_ДАТА_ВРЕМЯ/

Python-зависимости не менялись.
