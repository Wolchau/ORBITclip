ORBITclip SQL Explorer 7.3.0 — патч поверх 7.2.2

1. Полностью закрой ORBITclip (на Windows также через трей).
2. Распакуй патч рядом с установленным приложением.
3. Запусти install_windows.bat либо install_mac.command.
4. Скрипт проверит SHA-256, создаст резервную копию и обновит файлы.
5. При следующем запуске launcher.py установит psycopg[binary] при наличии интернета.

Пароли PostgreSQL НЕ сохраняются в настройках или JSON рабочего проекта.
