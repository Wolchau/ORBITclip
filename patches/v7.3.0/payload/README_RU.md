# ORBITclip 7.2.1

Компактный менеджер буфера обмена, личных и общих пространств, зашифрованной переписки, OCR и снимков экрана.

**Установка:** для Windows запусти `start_windows.bat`, для macOS — `start_mac.command`. Нужен Python 3.10+; библиотеки устанавливаются в локальную `.venv` автоматически.

**Обновления интерфейса и ограничения:** см. `README_V721.md`. История, избранное, ключи устройств и настройки остаются в домашнем каталоге; изменение версии их не стирает.

**Внимание:** клиент содержит тестовый общий токен Render. Не распространять публично; перед production заменить токен на сервере и очистить историю Git и релизов.


## v7.2.2 · UX и умные действия

- Версия постоянно отображается в заголовках библиотеки, мессенджера, пространств и настроек.
- Подключение: Обзор / Устройства / По PIN / Сервер — четыре страницы без длинной формы.
- В библиотеке явные вкладки Личное / По приложениям / Общие пространства; источники приложений выбираются кнопками.
- В окне «Пространства» рядом с общими группами показываются личные коллекции по приложениям. Они **не** публикуются автоматически.
- Умные действия: окно сравнения «было/стало», диагностика JSON / SQL / CSV / Python и новые операции с таблицами. Все операции локальны; SQL не исполняется.
- Патчи устанавливаются отдельным `apply_patch.py` и создают резервную копию; существующие настройки не перезаписываются.

## SQL Explorer (с версии 7.3.0)

Открыть: меню часов или меню инструментов истории → SQL Explorer.
Укажи данные для подключения к PostgreSQL и выбери способ TLS.
Выбери рабочие таблицы, загрузи поля, добавляй комментарии и связи,
перетаскивай блоки ER-схемы. Метаданные рабочих наборов локальные.
Пароль хранится только до закрытия окна SQL Explorer.
Для продуктивных баз используй выделенную учётную запись с правами на чтение.
